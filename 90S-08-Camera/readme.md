# 摄像机锚点与偏移 Demo

按数字键切换第三人称镜头，用来对照 `SetCameraOffset` 和 `SetCameraAnchor`。

## 键位

进世界后先确认是第三人称（模组按键时会自动切到第三人称）。不要打开聊天框，否则数字键会变成打字。

| 按键 | 效果 | 调用 |
| --- | --- | --- |
| `1` | 默认第三人称 | Offset / Anchor 都设回 `(0, 0, 0)` |
| `2` | 只挪镜头 | 只设 Offset，Anchor 保持 `(0, 0, 0)` |
| `3` | 越肩 | Offset + Anchor |

建议对照顺序：按 `1` 看正后方 → 按 `2` 看人偏到画面一侧，再转一圈视角，人会晃 → 按 `3` 再转一圈，人更稳。

## 偏移怎么调

两个接口的三元组都是 `(左右, 上下, 前后)`，当前默认值在 `cameraConst.py`：

```python
OFFSET_SHOULDER = (1.0, 0.2, 0.0)   # 镜头往右、略往上
ANCHOR_SHOULDER = (0.0, 0.6, 0.0)   # 圆心抬到胸口附近
```

- 按 `2` 或 `3` 以后，如果镜头跑到左肩后面，把 `OFFSET_SHOULDER` 第一项改成负数，例如 `(-1.0, 0.2, 0.0)`。
- 人在画面里太高或太低，改第二项。
- 镜头太近或太远，改第三项。
- 转视角时角色还是在画面里飘，把 `ANCHOR_SHOULDER` 的第二项再加大一点。

设置不会存档，退出重进就会回到原版镜头。

## 注意

- `SetCameraOffset` 只对第三人称生效，第一人称调了看不见。
- 按键只在 `hud_screen` 下响应。如果 1/2/3 没反应，确认聊天框是关上的。
